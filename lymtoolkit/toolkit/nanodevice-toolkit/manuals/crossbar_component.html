NANODEVICE FUNCTION MANUAL

Cross Bar Array

Cross Bar 阵列：共享横向背栅行与纵向顶栅列，在每个交点形成器件并以 N+M 个 Pad 引出。Creates shared horizontal bottom-gate rows and vertical top-gate columns with N x M crossings and only N + M pads.
