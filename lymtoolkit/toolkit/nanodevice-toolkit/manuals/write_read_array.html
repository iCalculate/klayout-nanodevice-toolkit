NANODEVICE FUNCTION MANUAL

Write / Read Array

Write / Read 阵列：将写入与读取晶体管、耦合 Via、门线和共享接触组合成可扇出的像素阵列。Combines write/read transistors, coupling vias, gate lines, shared contacts, and array fanout.
